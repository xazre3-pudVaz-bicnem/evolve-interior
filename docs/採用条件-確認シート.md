# 採用条件 確認シート（株式会社EVOLVE 様）

求人ページに掲載する労働条件を確定するためのシートです。
**当てはまるものに ✅ を付けるか、空欄に実際の数字をご記入ください。**

---

## ⚠ はじめに：なぜ「業界平均」では載せられないのか

給与・休日・福利厚生は、**EVOLVE社の実際の労働条件**です。
業界平均から推測した数字を求人ページに載せると、次のリスクがあります。

| リスク | 内容 |
| --- | --- |
| **法令違反** | 職業安定法第65条：虚偽の求人広告は **6ヶ月以下の懲役または30万円以下の罰金** |
| **応募者の辞退** | 「月給28万」を見て応募 → 面談で実際は違う → 辞退。悪い口コミも残る |
| **掲載停止** | Indeed・ハローワーク等は労働条件の不一致で掲載を止めることがある |

**実際の条件が分かれば、その日のうちに反映できます。**
（データ構造はすでに用意済みです。数字を入れるだけで画面に出ます）

現在、未確定の項目は求人ページに
**「詳細は面談時にご案内します」** と表示されています。
このままでも公開はできますが、給与が載っていない求人は応募率が大きく下がります。

## 記入後の反映方法（担当者向け）

`lib/recruit.ts` の該当箇所に値を入れるだけです。
`null` のあいだは「詳細は面談時にご案内します」と表示され、
値を入れると自動でその内容に切り替わります。

```ts
// lib/recruit.ts
{ label: '給与', value: '月給 220,000円 〜 400,000円', note: '経験・技能を考慮して決定します。' },
{ label: '休日・休暇', value: ['日曜', '隔週土曜', '祝日', '夏季休暇', '年末年始休暇'] },
{ label: '待遇・福利厚生', value: ['社会保険完備', '交通費支給（規定による）', '資格取得支援'] },
{ label: '選考の流れ', value: '応募 → 面談（1回） → 採用' },
```

給与が確定したら、JobPosting 構造化データも有効化します。

```ts
export const JOB_POSTING_DATA: JobPostingData = {
  employmentType: 'FULL_TIME',   // 確認済み
  baseSalaryMin: 220000,         // ← 実際の下限
  baseSalaryMax: 400000,         // ← 実際の上限
  salaryUnit: 'MONTH',           // 月給なら MONTH、日給なら DAY
  datePosted: '2026-07-14',
  validThrough: null,
}
```

これで **Google しごと検索（Google for Jobs）** に掲載されるようになります。
